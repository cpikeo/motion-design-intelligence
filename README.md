# motion-design-intelligence

面向网站、数字产品、品牌体验、交互叙事与数字展览的专业动态设计智能。承担资深动态设计总监与动态艺术指导的职责：原创动态概念、品牌运动识别、动态艺术指导（构图、镜头、摄影、排印、物理、光色、节奏）、引擎无关的 Motion Specification、交互与状态设计、响应式与无障碍降级、可追溯证据与真实运行验收。

**先判断为何运动，再决定如何运动，以及何时必须静止。** 不以效果数量、术语密度或文档长度证明专业。

## 它解决的问题

多数动效产出失败在三个地方，本 Skill 针对性约束：

1. **概念从效果起步**——先想到"淡入上移""视差""粒子"，再找理由。这里要求从事实（F）推导命题、母题、原则（P），并用四道测试（替换／识别／剥离／延展）判定是否只是通用套用。
2. **规格落不了地**——写着"自然一点""高级感"，工程师只能猜。这里规定三层（意图／行为／绑定）与必填字段，未定值必须标 `tbd(owner, due)`。
3. **验证靠截图与自述**——"看起来流畅""已适配移动端"。这里用 R/S/D/U 分级，运行类结论只认真实运行证据，未测即写未验证。

## Motion Specification：核心行为 + 扩展族

规格层不追求"效果名大全"，而是**有限核心词汇 + 可扩展行为契约**：

- **6 项核心行为**（封闭）：`fade`、`translate`、`scale`、`rotate`、`reveal`、`morph`。覆盖几何与显隐，附带参考系（frame）与语义原点（origin）。
- **7 个扩展族**（按需启用）：`camera`（视点）、`path`（路径）、`type`（排印）、`deform`（形变）、`light`（光材）、`time`（时间重映射）、`data`（数据驱动）。

启用任一族必须写全八项：语义、参考系、关键参数、状态控制、中断策略、响应式、无障碍替代、降级与验收。缺项即不可交付。核心词表只覆盖几何，专业运动不被硬塞进六个盒子里。

设计意图不依赖 GSAP、CSS、WAAPI、Rive 或任何单一引擎：换引擎后概念、用户收益与验收条件仍须成立。

## 验证状态

三个真实可运行项目（品牌官网／数字产品／中文编辑叙事）已完成端到端实现与浏览器内实测，共 32 项自动化用例通过，产物与脚本在 `_validation/`：

| 项目 | 追踪到的运动逻辑 | 结果 |
|---|---|---|
| NADIR 55/1.4 品牌官网 | 合焦即止：全站唯一一次离焦收敛，随后强制静止 | 10/10，稳态帧 p95 16.8 ms，LCP 中位≈600 ms（静态≈450） |
| RECON 对账台 数字产品 | 变更痕迹：只动被改单元，衰减后留非颜色标记，高频收敛 | 12/12，同格 50 次并发≤1，键盘全流程 |
| 《行与字》中文编辑叙事 | 断行处静止：正文零运动，标题按视觉行落位，横竖排离散切换 | 10/10，行首禁则违规 0，CLS 0 |

实测中定位并修复了 6 个缺陷。其中 2 个只有真实运行才会暴露：Enter 提交后同一按键重复触发；以及一处**归因错误**——首轮把长帧归因于模糊半径，复测推翻了该归因，真正来源是首绘与解码窗口。这条被写进 12.4：性能证据必须分离冷启动与稳态、至少采样 3 次。

**边界（不可越过地宣称）：** 单机单浏览器（Windows / Chrome headless / AMD Vega 8 iGPU）；未做真机矩阵、真实辅助技术朗读、用户测试、跨浏览器验证。品牌与产品事实为设计简报（E3），不是真实客户委托。

## 与动效知识库的区别

动效知识库回答"有哪些效果、参数是多少"。本 Skill 回答"这个项目为什么需要运动、该动哪里、哪些必须不动、怎么把它写成工程师不会误解的契约、以及如何证明它真的成立"。

静止是设计决策，不是默认状态；能删掉的运动比能加上的运动更值钱。
